
# XQuAD.uz: A Multilingual Benchmark for Question Answering in Uzbek

Dataset Summary:
XQuAD.uz is the Uzbek translation of the XQuAD (Cross-lingual Question Answering Dataset), designed to evaluate the performance of multilingual language models on the Uzbek language. It includes question-answer pairs that test a model’s ability to understand and respond accurately in Uzbek.

Languages:
Uzbek (Latin script)

Use Cases:

- Benchmarking the performance of multilingual and Uzbek-specific language models in question answering tasks.
- Fine-tuning language models to improve their performance on Uzbek natural language understanding.

Dataset Structure:

Format: JSON

- context: The passage from which the question is derived.
- question: The question related to the context.
- answers: A list of possible correct answers with their start indices in the context.
- id: A unique identifier for each question-answer pair.

Intended Use:
XQUAD.uz is intended for researchers and developers working on natural language processing (NLP) tasks for the Uzbek language, especially in the field of question answering.
